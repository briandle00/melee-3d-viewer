The GX player's simulator module (gx-core.js, gx-core.wasm) and its game file list (sim-files.json).

Built from melee-sim-light (https://github.com/briandle00/melee-sim-light, a fork of https://github.com/kyhavlov/melee-sim-light),
commit 7a9da9e5270c8e563c3f26d1146f59203c941a84 (branch perf/open, on gx-viewer 119be522: the float rule for a sum's own product, native libm calls, fighter facing in the effect callback): the viewer build with the HUD layout option (msl_gxw_set_hud_layout), the stream restart and memory-top
calls the app's player seeks with (msl_gxw_restart_stream, msl_gxw_heap_top), and the game data load kept for the next match
(msl_gxw_load_game, msl_gxw_rewind: a restart or a C-stick fit drive opens in milliseconds). Built with tools/build/build_wasm_gx.sh from a clean
build folder, DATA unset: no game data is inside the module (the page hands it the user's own files, main.dol included).
Source-file names are relative (prefix maps); gx-core.js has its two CRLF line ends written as LF.

sha256
  gx-core.js    dcb2ff99d6056d366ace4f39e928f873c60f2a6f4bdd6a3fc11bdb401d722af4
  gx-core.wasm  8de29593c5bd841167ecc61809b9fec4879f231867ad45ccfbfd4d6823e5b86f

sim-files.json lists the game files the module reads (names only), for a game folder given by URL (?files=).
