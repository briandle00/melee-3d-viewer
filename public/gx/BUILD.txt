sim-files.json lists the game files the module reads (names only), for a game folder given by URL (?files=). The sound files are not in
it: the module names them when the sound starts (audio/us/smash2.sem, the match's audio/us/*.ssm banks, the stage's audio/*.hps).

sim-files-match.json is made by the module itself, from a folder of the game's files:
  deno run -A --sloppy-imports tools/gx-match-files.ts <game files folder> [--keep-bases]
(a load of every match's records each file's console base; then each fighter's, Kirby copy's and stage's load notes the files it
opens, and a spread of matches is checked to read nothing beyond their parts). It holds file names only. A match loads only its own
game data when the folder holds those bases as msl-dat-bases.bin (sim/gamefiles.ts datBasesOf makes it from a whole load's record;
--keep-bases writes one beside the module for a local build): it is made from the player's own files and never committed. Without
it the module loads every match's game data, as before. Make sim-files-match.json again with every new module.
